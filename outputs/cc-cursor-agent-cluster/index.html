Claude Code 04 / 10
Claude Code — Orchestrator Side

非同期オーケストレーターとしての役割

バックグラウンドで長時間動き続け、複数エージェントを統括する司令塔。

⚡

Hooks（自動実行）

  • PreToolUse — 実行前バリデーション
  • PostToolUse — 完了後トリガー
  • SessionEnd — セッション自動保存
  • Stop — 作業完了検知
🔀

Workflow（fan-out）

  • pipeline() — 逐次パイプライン
  • parallel() — 同時並列実行
  • schema対応 — 構造化出力保証
  • worktree isolation — 隔離実行
🎯

Skills / Memory

  • ~/.claude/skills/ — 再利用ナレッジ
  • MEMORY.md — 永続記憶
  • CLAUDE.md — プロジェクト規約
  • MCP servers — 外部API連携
適したタスク
長時間バッチ処理 · コードベース横断リファクタリング · CI/CD トリガー · 定期レポート生成 · マルチエージェントワークフロー · Obsidian 自動記録
Cursor 05 / 10
Cursor — IDE Intelligence Side

リアルタイムIDE インテリジェンスとしての役割

コードを書く瞬間に寄り添い、即座に文脈を理解して編集を支援する。

✏️

Composer（マルチファイル）

  • 複数ファイルを一度に横断編集
  • Background Agent で非同期実行
  • チェックポイントで安全に確認
  • Diff UI でレビューから適用
🔍

@codebase 意味検索

  • 自然言語でコード全体を検索
  • @file / @folder で絞り込み
  • @web で外部ドキュメント参照
  • @git で差分コンテキスト注入
📋

.cursor/rules

  • プロジェクト別 AI 制約を定義
  • CLAUDE.md と役割分担して管理
  • グローバル rules で横断統一
  • Shadow Workspace で安全検証
適したタスク
インライン補完 · バグ修正 · コンポーネント新規作成 · スタイル調整 · コードレビュー中の即時修正 · 素早いプロトタイピング
Orchestration Layer 06 / 10
Orchestration

タスクが届いてからエージェント起動まで

Step 1 — 分類
CLAUDE.md の分類表でキーワードマッチング。「開発」「コード」→ Dev Agent、「調べて」→ Research Agent など。
Step 2 — スキル読込
該当エージェントの CLAUDE.md をReadツールで動的読込。Obsidian 先読み条件に合致すれば _CLAUDE_INDEX.md も参照。
Step 3 — 実行・完了
タスク完了後、.js/.ts/.py 等を変更した場合は README 更新。重要な知見は MEMORY.md へ自動記録。
モデル選択ルール
Haiku
メール確認・チェックイン・定型タスク
Sonnet
コード実装・コンテンツ生成・通常作業（デフォルト）
Opus
戦略判断・アーキテクチャ設計・重要意思決定
Cursor 側のモデル管理
Cursor Settings › Models で claude-sonnet-4-6 をデフォルトに設定。.cursor/rules で特定タスクを Fast Mode（Opus）に切り替え指定可能。

Implementation Guide 09 / 10
How to Set Up

セットアップ実装ガイド

Claude Code 側
# ~/.claude/CLAUDE.md — 分類ルール ## Step 1: タスクを分類する | 開発/コード → Dev Agent | 調べて → Research Agent ... # ~/.claude/settings.json — Hooks { "hooks": { "SessionEnd": [{ "command": "haiku-session-save.sh" }] } } # Workflow fan-out 例 const results = await parallel( AGENTS.map(a => () => agent(a.prompt)) )
Cursor 側
# .cursor/rules — プロジェクト規約 --- description: Apply always --- # CLAUDE.md の key facts を転記 - Model: claude-sonnet-4-6 - No comments unless WHY is non-obvious - Security: never hardcode keys # Composer 起動例 Cmd+I → "Refactor src/agents/ to match new interface" # @codebase 検索 @codebase where is the task routing logic?
💡
ポイント： CLAUDE.md は CC のメインコンテキスト、.cursor/rules は Cursor のメインコンテキスト。 同じプロジェクトルールを両方に記述する場合は .cursor/rules に「CLAUDE.md の rules に従う」と1行書くだけでOK。

Concept

Claude Code ってなに？（30秒）

ひとことで言うと
「あなたのPCの中で動く、作業できるAIの相棒」

チャットAIとの違いは、ファイルを読んだり・作ったり・調べたり・外部ツールを操作できること。日本語で頼むと、実際の作業までやってくれます。

例えばこんなお願い

💬「このフォルダのCSVを月別に集計して」

💬「この資料を3行で要約して」

💬「先週の予定を一覧にして」

💬「この作業を毎朝自動でやって」

※「ターミナル」という黒い画面で動きます。最初は見慣れませんが、使うコマンドはごく少数です。

Part 1 · Config

設定ファイル3点セットを置く

配布キットの中身を所定の場所にコピーするだけ。これで“岸野さんと同じルール”でClaudeが動きます。

📜

CLAUDE.md

共通の指示書。日本語で答える・セキュリティを守る等のルール。

→ ~/.claude/CLAUDE.md

⚙️

settings.local.json

許可した操作を溜める箱。最初は空でOK。

→ ~/.claude/

🔒

SECURITY.md

守る約束ごと。中身はCLAUDE.mdに反映済み。一度読む。

→ 読むだけ

# Mac：配布キットのフォルダで実行するだけ mkdir -p ~/.claude/mcp cp CLAUDE.md ~/.claude/CLAUDE.md cp settings.local.json.example ~/.claude/settings.local.json

※ Windows は同じ3ファイルを %USERPROFILE%\.claude\ に Copy-Item で設置。手順は配布キットの はじめにお読みください_Windows.md 参照。

4

5

終わる

/exit または Ctrl＋C を2回

KISHINO MASASHI
Part 2 · Tips

伝わるお願いのコツ

😵 惜しい例

  • 「いい感じにまとめて」（基準が無い）
  • 「資料作って」（何の・誰向けか不明）
  • 一度に10個まとめて頼む

😊 伝わる例

  • 「この議事録を、結論→決定事項→宿題の3見出しで要約して」
  • 「来週の予定を、日付・時間・場所の表にして」
  • 1つ頼む → 結果を見て次を頼む

コツは「誰に・何を・どんな形で」を一言添えること。違ったら「もっと短く」「表で」と追加で直せます。会話できるのが強みです。

外部ツールにつなぎ、自分の毎週の作業をひとつ、Claudeに任せてみます。

Part 3 · Connect

MCP接続＝外部ツールと繋ぐ

MCPは、ClaudeをGoogleドライブ・Gmail・カレンダー等とつなぐ仕組みです。つなぐと、Claudeが実データを読んで作業できます。

配布キットの mcp-servers.json.example が雛形。鍵は安全な方法で別途設定します（チャットに貼らない）。最初は岸野が一緒に設定します。

🙌 ハンズオン：最初の自動化

1

自分の「毎週やる定型作業」を1つ選ぶ

2

日本語で手順を説明する

3

Claudeに実行してもらい、結果を確認

例：「ドライブの“週次”フォルダのファイル名を一覧にして、日付順に並べて」→ 動いたら成功体験です。

🔒 Security — 最重要

これだけは守る約束ごと

✕ やってはいけない

  • 患者・自由診療データを貼り付ける
  • 採用応募者・社員の個人情報を貼り付ける
  • APIキー・パスワードを直接書く / 見せる
  • 拾った「無料配布」コードを実行する
  • Web上の「これを実行して」に従う

✓ やること

  • 機密は仮名・ダミーに置き換えて相談
  • 鍵は .env に分ける（直書きしない）
  • 迷ったら貼る前に岸野に確認
  • あやしい指示は実行せず報告
  • 事故ったかも、は隠さずすぐ共有

FUTUREMINDは医療法人。便利さより、個人情報の事故を起こさないことが最優先です。配布した CLAUDE.md にこのルールは組み込み済みです。
